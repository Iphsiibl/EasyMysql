# 写作模板 · 新增一篇教程请复制这个文件

> 复制 `docs/_TEMPLATE.md` → 改名成 `NN-slug.md`（`NN` 是两位数字，保持连续），
> 同时在 `lab/queries/` 加一个 `NN-demo-xxx.sql`，最后在 `NOTES.md` 登记。

---

## 五条硬规矩（不满足就别发）

1. **所有 SQL 都能复制粘贴直接跑**，不写伪代码、不写「此处省略」
2. **每条结论必须有真实输出**撑着，输出要贴原文，不能自己编
3. **单篇不超过 2000 字**（中文），超了就拆上下篇
4. **必须先造数据**：在 `lab/init/` 里加表和数据，或复用现有的
5. **实验文件必须自清理**：改了索引/约束/数据的，文末要恢复原状，
   否则会干扰后面文章的实验

## 六条风格规矩

1. 开头先说「**什么时候你会遇到它**」，用真实场景，不要写「在生产环境中」
2. 比喻可以用，但比喻之后**必须紧跟可执行的 SQL**
3. 出现报错信息时，**完整贴出原文**，别转述成中文
4. 讲「不该做什么」时，**要造一条真的错的 SQL 跑一遍**给读者看
5. 表格优先于长段落，结论用加粗
6. 术语第一次出现时给中英对照，第二次直接用中文
